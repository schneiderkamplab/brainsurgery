# Axon To Synapse Stages

This maps the pipeline from `.axon` source text to lowered Synapse graph/spec.

| Stage | Code Location | Interface | What it does |
|---|---|---|---|
| 1. Raw text -> parsed source tree | `/work/training/brainsurgery/brainsurgery/synapse/axon/grammar.py` | `parse_program_source(source: str) -> ParsedProgramSource` | Uses Lark grammar/transformer to parse `.axon` text into a structured parsed source object (modules, imports, exports, pragmas, constants, type aliases). |
| 2. Parsed-source syntax validation | `/work/training/brainsurgery/brainsurgery/synapse/axon/syntax_validation.py` | `validate_parsed_program_source(parsed_source)` | Checks declaration-level syntax/consistency not handled by grammar alone (module decl match, import/export consistency, required returns in `do`, etc.). |
| 3. Parsed source -> Axon AST modules | `/work/training/brainsurgery/brainsurgery/synapse/axon/parser.py` | `build_axon_modules_from_parsed_source(...) -> tuple[AxonModule, ...]` | Converts parsed source into AST nodes (`AxonModule`, statements/expr nodes), injects constants/symbol metadata/pragma payload. |
| 4. File-level load/import resolution | `/work/training/brainsurgery/brainsurgery/synapse/axon/parser.py`, `/work/training/brainsurgery/brainsurgery/synapse/axon/import_loader.py` | `parse_axon_program_from_path(path) -> tuple[AxonModule, ...]` -> `load_axon_program_from_path(path)` | Reads `.axon` file(s), resolves `import` dependencies, loads Prelude/builtins, applies namespacing/re-exports, and produces one merged module tuple. |
| 5. AST structural validation | `/work/training/brainsurgery/brainsurgery/synapse/axon/ast_validation.py` | `validate_axon_program(modules, main_module=None) -> None` | Ensures AST invariants (non-empty program, no duplicate module names, valid statement/return structure, arity sanity, main module exists). |
| 6. Type checking | `/work/training/brainsurgery/brainsurgery/synapse/axon/typecheck.py` | `typecheck_axon_program(modules, main_module=None) -> dict[str, ModuleSignature]` | Infers/checks expression and module signature types, validates calls/defaults/returns, and enforces primitive op typing contracts. |
| 7. Lowering AST -> Synapse spec/graph | `/work/training/brainsurgery/brainsurgery/synapse/axon/lowering_core.py` | `lower_axon_program_to_synapse_spec(modules, main_module=None) -> dict[str, Any]` | Lowers typed Axon modules into Synapse model/block graphs (`model.graph`, optional `model.blocks[*].graph`), with resolved IO bindings. |
| 8. Lowering post-pass (path/scoping rewrites) | `/work/training/brainsurgery/brainsurgery/synapse/axon/lowering_core.py` | `_resolve_paths_at_lowering_time(model, block_path_params, ...)` (internal) | Rewrites/normalizes path-bound references and block call path semantics so produced graph nodes are executable/resolved. |
| 9. Primitive op contract lookup used by typecheck/lowering | `/work/training/brainsurgery/brainsurgery/synapse/ops/__init__.py` | `get_op_lowering_signature(...)`, `get_op_lowering_type_signature(...)`, etc. | Provides per-op signatures/validators/metadata hooks that govern correctness and metadata during typecheck/lowering. |
| 10. Typical orchestration call site | `/work/training/brainsurgery/brainsurgery/synapse/axon_test.py` | `modules = parse_axon_program_from_path(...)`; `synapse_spec = lower_axon_program_to_synapse_spec(...)` | Concrete end-to-end usage that turns an Axon file into a Synapse graph/spec for codegen/runtime. |
