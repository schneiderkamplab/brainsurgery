# Competing-tool preflight records

These compact records establish that the frozen cases, actual tool adapters,
and independent oracle integrate successfully. They are deliberately not paper
performance results. Reportable Linux results must pass every gate in
`../protocol.md`; raw records stay below `log/revision_tests/` and are not
committed.

The macOS record is available as machine-readable JSON, a correctness-only
LaTeX table, and a standalone interpretation. The LaTeX fragment intentionally
suppresses non-reportable timing and memory measurements.
